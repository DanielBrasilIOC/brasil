# Painel Financeiro e Orçamentário IOC

Dashboard web para acompanhamento financeiro e orçamentário, com interface em cores suaves.

## Privacidade
Este repositório é público. Não publique aqui planilhas, saldos reais, identificadores de contas ou outros dados financeiros internos.

## Publicação
O arquivo principal `index.html` será disponibilizado após revisão para garantir que não contenha dados financeiros reais. A habilitação do GitHub Pages pode exigir uma etapa nas configurações do repositório.
